# Electricity and Gas Consumption Fraud Detection

## Project Overview
This project detects fraudulent electricity and gas consumption using machine learning techniques. A Random Forest model is trained to identify abnormal consumption patterns.

## Features
- Data preprocessing
- Exploratory Data Analysis
- Random Forest model training
- Fraud prediction
- Streamlit web application

## Technologies Used
- Python
- Pandas
- Scikit-learn
- Streamlit
- Matplotlib

## Project Structure
data/ → dataset
notebook/ → model training
app/ → Streamlit interface
model/ → saved model

## How to Run
pip install -r requirements.txt
streamlit run app/streamlit_app.py

## Results
Accuracy: 92%
